# Donkey Kong – C++ Console Game

## Overview
A Donkey Kong-inspired console game developed in C++ using Visual Studio as part of an academic Computer Science project.

The game features Mario navigating through multiple levels, avoiding obstacles and enemies, and using a hammer to overcome challenges.

## Features

- **Multi-Level Gameplay:** Supports loading game levels from external screen files.
- **Player Controls:** Mario can move, jump, and climb ladders.
- **Enemies and Obstacles:** Includes barrels, ghosts, and climbing ghosts.
- **Enemy Behavior:** Climbing ghosts can chase Mario when he enters a specific detection radius.
- **Hammer Mechanic:** Mario can use a hammer to destroy nearby obstacles and enemies.
- **Timer System:** Optional five-minute time limit for completing a level.
- **Visual Effects:** Animations for barrel explosions and hammer usage.
- **Sound Effects:** Audio feedback in the game menu.
- **Customizable Display:** Players can enable or disable colors and the timer.
- **File Validation:** Detailed error messages for invalid characters and screen configurations.

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Visual Studio
- Windows Console
- File Handling

## Technical Highlights

- Modular game architecture using C++ classes.
- File-based level loading and validation.
- Keyboard input handling and real-time game updates.
- Enemy movement and pursuit behavior.
- Console-based rendering with ASCII characters and colors.

## How to Run

1. Open the `.sln` file in Visual Studio 2022 or later.
2. Build the solution.
3. Make sure the required level files are available in the working directory.
4. Run the game in a Windows console.
